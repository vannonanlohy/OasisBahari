# Catatan Workshop / Proyek Web Pariwisata Bahari

## 1. Tujuan Latihan
Membuat sistem informasi direktori wisata laut dan *hidden gems* Nusantara berbasis web yang dilengkapi dengan peta interaktif (OpenStreetMap), sistem filter kategori, halaman detail destinasi, fitur wishlist, halaman About Us, serta dashboard admin untuk pengelolaan data (CRUD).

## 2. Target Aplikasi
* **Frontend (Pengunjung):** Halaman beranda dengan peta sebaran interaktif, pencarian, filter kategori/wilayah, halaman detail tempat (lengkap dengan tips lokal, info akses, dan checklist), halaman wishlist pribadi, serta halaman About Us.
* **Backend (Admin):** Dashboard pengelola untuk memantau statistik, mengelola data destinasi wisata (tambah, edit, hapus, atur *featured*), dan mengatur peta titik koordinat.

## 3. Risiko Penggunaan AI yang Ingin Diperiksa
Ketepatan data geografis (koordinat latitude/longitude) serta kesesuaian informasi akses dan deskripsi spot *hidden gems* yang dihasilkan oleh AI, guna memastikan keakuratan informasi bagi wisatawan di lapangan.
